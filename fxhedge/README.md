# HalalFlow — the app

This is the Next.js application. The full product README (what HalalFlow is, the three golden rules, engines, data sources, setup, and API) lives at the [repo root](../README.md).

Quick start:

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # engine unit tests
```

Supabase keys go in `.env.local` (see the root README for the full setup).
